# Chatbot-TECNOM 🤖

Asistente conversacional interactivo desarrollado en **Python** utilizando el framework **Streamlit**.

## 📋 Características principales

* **Interfaz web interactiva:** Construida íntegramente en Python mediante Streamlit para facilitar una experiencia de chat fluida.
* **Entorno reproducible:** Gestión clara de librerías y dependencias externas a través de `requirements.txt`.
* **Configuración personalizada:** Ajustes de tema y comportamiento de la aplicación definidos en la carpeta `.streamlit`.

## 🛠️ Tecnologías utilizadas

* **Lenguaje:** Python 3
* **Framework Web:** Streamlit
* **Control de versiones:** Git y GitHub

## 📂 Estructura del repositorio

```text
Chatbot-TECNOM/
├── .streamlit/        # Configuración de la interfaz de Streamlit
├── app.py             # Código principal de la aplicación y lógica del chatbot
├── requirements.txt   # Dependencias necesarias para ejecutar el proyecto
└── README.md          # Documentación del proyecto
```
